# Concepts and Script Rules

## Ten commercial concepts

Generate exactly 10 distinct concepts. Each should contain:
- Product
- Campaign title
- Strong hook
- Customer problem or desire
- Product solution
- Emotional or visual payoff
- Final advertising message
- Recommended visual style

The concepts should feel like real premium campaigns, not generic taglines.

Use natural contemporary American settings and language unless the user requests another market.

Do not create storyboard panels or images at this stage.

## Selected concept lock

Once the user selects one concept, treat that choice as approved until the user changes it.

## Script

Fit the script to the selected duration. Build a coherent progression from attention/hook through experience and payoff to the brand message.

Keep character actions physically plausible. Use product behavior that is visible, provided, or broadly generic; do not invent unsupported product claims.

Keep dialogue short. Use voiceover only when it improves clarity or emotional pacing.

The script is text only. Do not create a storyboard image until the storyboard-plan stage.
