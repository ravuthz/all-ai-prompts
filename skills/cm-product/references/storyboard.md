# Storyboard Rules

## Plan first

A storyboard image is allowed only after a complete storyboard plan exists.

Every shot in the plan should state:
- shot number
- approximate duration
- action
- characters present
- product presence
- location
- dialogue/voiceover
- camera/framing/movement
- continuity notes

Each shot should represent one clear visual moment.

## Complete storyboard image

Generate one standalone complete storyboard image. It must:
- show the full commercial in order
- number shots clearly
- correspond directly to the plan
- preserve locked character identity
- preserve locked product design
- preserve locked location identity
- reflect the selected duration and script
- end on the intended brand/product payoff

It may include concise shot labels, durations, brief dialogue/VO cues, and camera composition.

It must not contain:
- a separate character sheet
- a separate product sheet
- a separate location sheet
- unrelated references
- alternate campaign concepts

## Visual continuity priorities

When a storyboard rendering conflicts with a locked reference:
- character appearance follows the character reference
- product design follows the product reference
- location design follows the location reference
- shot order/action follows the storyboard plan and script
