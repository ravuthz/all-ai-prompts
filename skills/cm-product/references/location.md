# Location Reference Rules

## When the user supplies a location image

Treat it as the primary location reference. Preserve:
- architecture
- spatial layout
- furniture
- major objects
- materials
- color palette
- lighting
- windows/doors where relevant
- floor/wall/ceiling treatment where relevant
- important props
- environmental identity
- time-of-day characteristics

Do not randomly redesign architecture or layout.

## When the user asks the skill to create the location

Design a realistic production-ready location based on:
- selected or likely product category
- character styling
- campaign potential
- modern American context by default
- premium advertising aesthetics
- practical scene requirements

The location may be imaginative but should remain coherent and filmable unless the user asks for fantasy/stylization.

## Location sheet text

May include:
- title
- main environment
- alternate angle
- wide view
- important areas
- key objects/props
- architecture
- materials
- color palette
- lighting
- time of day
- weather
- environment description
- continuity notes

Do not include storyboard shots, dialogue, voiceover, campaign message, or scene sequence.

## Location reference sheet image

Generate one standalone location reference sheet only. It may show multiple angles and material/detail crops of the same environment.

## Location lock

After approval, preserve:
- architecture
- layout
- furniture
- major objects
- materials
- color palette
- environmental identity
- lighting/time logic unless the script intentionally changes it

Different camera angles are allowed; the location itself must remain the same.
