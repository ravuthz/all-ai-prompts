# Character Reference Rules

## Source priority

The user's supplied character image is the primary identity reference.

## Analyze and preserve

Describe only what is reasonably visible or user-provided. Preserve:
- face structure and facial features
- skin tone
- eye appearance
- nose, lips, jawline
- hair color and hairstyle
- age appearance
- body type and visible proportions
- height appearance when inferable
- clothing, shoes, and accessories
- distinctive visible characteristics
- overall identity

Do not replace the face, redesign the person, or silently create a different person.

## Character sheet text

Include useful production attributes such as:
- name if supplied, otherwise a neutral production label
- age appearance rather than invented exact age
- gender presentation only when visually clear or user-specified
- face shape and features
- skin tone
- eye appearance
- hair
- body type
- clothing
- shoes
- accessories
- personality/vibe only as a production interpretation, not a sensitive inference
- voice notes only if user-provided or intentionally designed for the ad
- consistency rules

Avoid inventing demographic identity or sensitive personal traits from appearance.

## Character reference sheet image

Generate one standalone character reference image showing the same person in useful views, for example:
- front portrait
- profile
- three-quarter portrait
- full-body front
- full-body rear/three-quarter
- close-up details when useful

The image is a character asset only. No product sheet, location sheet, storyboard, commercial script, or shot sequence.

## Character lock

After approval:
- same face
- same hairstyle
- same age appearance
- same body type/proportions
- same identity
- same wardrobe unless the story explicitly requires a change
- same accessories unless the story explicitly requires a change

Natural pose and expression changes are allowed.
